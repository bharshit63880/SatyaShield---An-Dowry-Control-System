# Accessibility and translation status

The interface targets WCAG 2.2 AA-oriented engineering with semantic landmarks, skip navigation, visible focus, keyboard-operable controls, focus-managed dialogs, live regions, reduced-motion support, touch-friendly controls, and responsive English/Hindi layouts.

Automated translation parity and classified visible-string inventory checks prevent missing catalog entries. English is the fallback. Hindi copy is an internally reviewed draft and is not professionally, legally, or government certified. Safety, privacy, evidence, authentication, delivery, and non-dispatch wording requires qualified language/legal review before public operational use.

Automated axe coverage does not establish conformance. Manual Windows Narrator, keyboard, zoom/reflow, and real-device review must be recorded before a readiness claim.
